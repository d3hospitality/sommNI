# sommNI 3.7.53 beta

Wine by Grape adds Search by Voice and Saved Locations before the existing styles. The speech capture uses the existing explicit G2 microphone/transcription service, a six-second bound, cancellation, timeout, and serialized bridge traffic. Search matches only actual saved or collective catalog records by name, producer, vintage, grape, origin and saved location; accents and filler words normalize, numeric tokens match whole words. Saved vintages take precedence over the same canonical catalog identity. Results reuse the continuous Winebrary bottle/map view and notes. Search-again, no-match, Back, microphone cancellation, background pause and display release remain reachable. Search neither adds a wine nor runs bottle research.

Restaurant/location names are list memberships, separate from country/region of origin. The existing menu/PDF/photo/typed batch accepts an optional 120-character location name, suggests already saved names, and repeats the list name in review. Existing exact wine/producer/vintage matches can join a named menu list and skip research/confirmation duplication. Possible/unknown vintage matches retain review. Saving adds membership to the latest saved wine metadata. Manual wine editing can maintain a newline-separated list of locations. The same wine may appear at many venues with one personal record. Guest imports merge memberships into existing account wines; edits preserve other metadata and artwork.

Phone Winebrary gains a compact Saved Location selector. View All resets it, account changes clear it, and expanded rows show membership. Glasses Winebrary and Wine by Grape both expose Saved Locations, with counts, pagination, a useful empty state, and scoped continuous wine browsing. The user's collective-submission pipeline remains intact; restaurant membership is not incorrectly used as the wine's geographic origin or exposed as a verified public restaurant menu. It is saved in existing user_collection metadata with existing owner-scoped access, guest device storage and backups. No schema, permission or service-key change.

Validation: both TypeScript projects, all 44 serial beta tests, site build, API dependency check, production package build and URL allowlist audit passed. Tests cover speech results/cancel/pause/mic close, notes and Back restoration, restaurant scoping and bottle hover, exact-vintage duplicate handling, repeated account import with merged venues, named-menu approval, and phone filter reset. The cloud collection tests use a controlled account/database fixture; no fake wine was uploaded to the live collective and no live transcription was purchased. Physical G2 microphone quality and BLE response still require device confirmation.

Portrait UI reviewed in the running companion at 390x844 with the actual production import components. New restaurant field fits and retains gold focus styling.
