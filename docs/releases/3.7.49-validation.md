# sommNI 3.7.49 beta

Companion continuity update on top of 3.7.48's compact Home, live weekly contributions and linked-account profile/photo editor.

- Atlas defers glasses selections while offscreen, hidden or covered, then catches up to the latest selection when visible. Identical device context does not reset independent phone browsing. The selected bottle's region/state focus follows it; leaving a stale regional filter restores the country bottle deck.
- Open on glasses resolves the phone's country, region and exact bottle IDs against the current catalog/account. A personal vintage takes precedence over its public reference. Missing wines fail without claiming the display. Bordeaux/Burgundy parent groups and appellations remain navigable; Back stays within Atlas.
- Pairing completion replaces the code controls with Edit My Profile and Open Winebrary. Already-linked users open account management. Account management links directly to Settings' profile editor; G2 confirms linking and points to phone Settings for profile/photo changes.
- On your glasses is a compact, initially collapsed row with the current wine. Expanded personal wines open their own Winebrary notes. Settings suppresses the companion so profile work stays focused. Account changes immediately clear private context and bottle selection.
- Album permission description includes private linked-profile photos. No permission, network whitelist, Supabase schema, public-catalog deletion policy, allowance or publication-schedule changes.

Validation: 35 serial beta checks, app and site TypeScript checks, site production build and packaged beta URL audit. Companion tests exercise deferred catch-up, stable manual browsing, null/reset, linked and unlinked pairing transitions, profile routing, private notes, account isolation, G2 page/container validation and graceful Home return. Phone handoff tests exercise country, region, public/personal bottle identity, stale/missing IDs, parent/appellation groups and Back navigation. Existing suite covers library hover images, image queue races, menus, profile ownership, uploads, batch jobs, guide, gestures, account allowances and shared-catalog behavior.

Portrait Chrome QA at 390x844 used a clearly labeled local G2 event fixture with real catalog data: Napa/Cain Cuvee to Oregon/Antica Terra, correct state framing, gold highlight, bottle and text; hidden Atlas catch-up and Settings isolation were verified. The temporary fixture was excluded from the package and removed after QA. Plain browser honestly leaves Open on glasses disabled.

Physical G2 hardware was not connected. Live pairing/auth and authenticated profile upload were not repeated; no real account or wine was mutated during QA. Screenshot evidence outside the repo: outputs/sommni-3.7.49/companion-atlas-fixture.png.
