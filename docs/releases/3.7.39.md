# sommNI 3.7.39 beta — 7 November 2026

- Portrait-first phone navigation, a simpler Home and collapsible tasks.
- Larger swipeable bottle overlay, magnetic country/region wheel, and circular dithered Atlas edges on phone and G2.
- Optional walkthrough with Skip/Back, dynamic centered positioning, target-aware placement and balanced button rows.
- Consistent full-width action rows in the guide, bottle-photo review and Winebrary; style filters fill every wrapped row.
- Upload Bottle Photo silhouette and Take Photo controls share the existing identification/cutout pipeline.
- Import PDF menus or photos by upload or public HTTPS link. Review extracted wines before research/saving; skip food/other drinks, flag unclear labels/years, and suppress duplicate producer/label/vintage entries.
- Contributor profiles with optional bio/location and public leaderboard opt-in. Verified unique contributions receive 10 points; reviewed shared wines publish Friday at 9 p.m. America/New_York. Personal saves remain immediate; master records are retained independently of personal removals.

## Validation and deployment

`npm ci`, `npm run test:beta` (20 suites), `npm run typecheck`, `npm run build`, `npm run pack:beta`.

The default app configuration is free beta. For a clean checkout set `VITE_WL_FREE_BETA=true` in `.env.local` before web development; `pack:beta` sets it automatically. API secrets belong only in the dedicated Supabase project.

Menu import was checked live against a 5-page mixed menu (45 wines) and a small menu image (23 wines, manual review required). Phone layouts checked at 320 and 390 px. G2 changes have renderer/bridge regression coverage; physical hardware was not tested for this release.

Supabase migrations through `20261107070015_friday_activity_publications.sql` are already applied; `winelens-beta` v37 is deployed. Do not reapply migrations blindly. Client source URLs are stripped/audited against the network whitelist.

This branch contains the current Even companion source. Older `site/` and `api/` trees are retained for history and were not redeployed by this release.
