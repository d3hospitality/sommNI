# sommNI 3.7.60 — Bottle texture and a continuous scan

## Changes

- Phone bottle displays use a restrained static ordered opacity texture. The central label band remains opaque. Original photographs, downloaded files and upload data are unchanged.
- G2 bottle portraits retain the existing seven grayscale tones. Static ordered dither applies only to opaque midtones away from sharp ink boundaries; black, transparency and bright paper stay intact. No extra display containers or periodic sends.
- Photo research optionally streams an identified name/producer/outline before web research and final structuring finish. Existing JSON clients still work. The same daily allowance, request reserve, source sanitization and explicit approval gate cover streaming requests.
- Mesh strands form a counter-wound cylindrical net inside the photographed outline, with a progressive reveal and traveling scan ring. Rendering is capped near 30 fps and respects reduced motion. No particle/splat effects or added ML runtime.
- Review shows a catalog reference photograph when the existing strict identity matcher returns exactly one wine; its vintage is explicitly marked potentially different. No ambiguous catalog fallback is substituted.

## Evidence

- All 53 beta test groups pass. Stream tests cover incremental UTF-8 chunks, progress before result, incomplete responses, preserved quota errors and backend-only source URLs. Session tests cover cancellation and stale-progress rejection. Dither tests preserve native tones, black/alpha, bright label paper and deterministic texture.
- 12 backend regression tests pass. App/site TypeScript, website build, stream helper Deno check and bundle URL audit pass.
- Live Supabase v50 test: the scanner shows a possible Grand Malbec / Terrazas de los Andes and an active reference stage before approval. Final match identified the visible 2017 vintage and showed the catalog bottle comparison. Test used a catalog photo composited onto a plain background; no test wine saved or contributed.
- Portrait phone comparison at 390×844 inspected. On the tested 244×244 glasses bottle, two compressed halves grew from 1,614 to 1,838 bytes (+224). This measures payload, not device latency or a guarantee for all photographs.
- winelens-beta deployed baseline v49 matched before update; v50 preserves its existing authentication, quotas, unrelated files and submission flow.

## Limits

The net is a 2D-photo-fitted volume effect, not measured 3D reconstruction. Until a reliable outline arrives, framing remains neutral rather than inventing bottle geometry. The Even host uses its native camera capture/picker; this is not an uninterrupted live-camera feed inside that WebView. Recognition and artwork matching remain suggestions requiring approval. Physical G2 latency and camera permissions were not remeasured. Streaming is enabled on the shared beta research endpoint used by this build; the separate account research endpoint retains its compatible JSON response.
