## Tool investigation

The SLAM dataset collection is for localization/mapping research, not a production bottle recognizer. Tested the existing U2NetP salient-object model and MediaPipe Interactive Segmenter 1.2.2 with its official Magic Touch model against the supplied photograph. U2NetP favored the hand; point segmentation selected only the paper label. Neither was reliable enough to add a 30 MB scanner dependency. The experimental dependency was removed. This release uses deterministic, lightweight label targeting and the existing verified vision backend. Its mesh is a photo-fitted visual overlay, not measured 3D depth.
