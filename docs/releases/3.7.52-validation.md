# sommNI 3.7.52 beta

Glasses Atlas now uses the existing administrative boundaries for selected-region context, including Veneto and Piedmont/Piemonte. Explicit wine-region administrative context (Bordeaux/Burgundy) is reused where available; other places retain an honest winery-cluster locator. Polygon holes are preserved. A stable dither texture breathes through three intensity levels, with a 1.8-second rest after each completed two-tile frame. Menu text is not rewritten during animation. Frames serialize, cursor movement invalidates old work, and close/pause/voice capture cancels the pulse. Reduced-motion users receive a still highlight. Compact PNG encoding reduces transfer size, with the existing WebView fallback.

Every country region menu offers Search by Voice followed by Nw · All Wines. The shortcut aggregates the current country and deduplicates repeated region-group references by entry identity, retaining saved-vintage and catalog entries as distinct sources. It supports every-wine scroll/selection, exact bottle previews through the existing source callback, country history and Back returning to All Wines. Existing Bordeaux/Burgundy regional shortcuts use the same capitalization/count format. Country-wide mode has no artificial region selected.

Home adds sommNI · Home above a separately indented eight-item text cursor. It retains > selection without a box and fits the existing 576×288 canvas. Pairings now declares the same single home-pour image container and reuses the existing dithered Japanese/Latin identity plus head-responsive glass. Forward/back pairing pagination repaints the artwork, and foreground restore resumes it. No new image or animation pipeline.

Wine History now retains display ownership while disconnected/backgrounded, consumes input while suspended, and restores the interrupted screen after reconnection/foreground entry. Relinquishing the display clears the pending restore so it cannot steal another module's screen. Rapid repeated Back events are debounced along with normal navigation; pending renders are revision-checked. History headings use title case.

Validation: 42 serial beta checks passed; both TypeScript projects and the site build passed. The region transport test was rerun after compact PNG encoding. Tests exercise actual Veneto/Piedmont geometry matching, polygon holes, intensity changes, country isolation, serialized transfers, menu stability, close cancellation and reduced motion. Navigation tests cover the All Wines aggregate, deduplication, every-item selection and Back restoration. All 228 current catalog history cards fit G2 reading limits; simulated history tests cover duplicate Back, disconnect/foreground restore and ownership transfer. Home/Pairings pages validate hardware container bounds. Package build and client URL audit passed.

Visual QA used the existing dev server and one temporary browser tab: production page builders, real Atlas geometry/catalog and the production glass raster were rendered at native G2 dimensions. Checked Home spacing, Italy's All Wines shortcut, Tuscany/Piedmont highlighting and Pairings artwork. The lightweight preview approximates native font/list styling; it is not a physical-device capture. Temporary fixture removed; screenshots outside the repository in outputs/sommni-3.7.52/. No physical G2 was connected. Actual BLE pulse smoothness and reconnection behavior still need on-device confirmation.
