# sommNI 3.7.45 beta

- Wine/menu selection uses broad tappable rows and gold/grey states. Country and expandable region controls include/skip eligible entries together; duplicates stay excluded. Editable identity fields do not accidentally toggle selection.
- Menu origins use explicitly extracted places and an exact, ambiguity-filtered index generated from the existing Atlas and catalog. Unresolved places remain separate; no country is guessed from producer names. Regenerate with `node scripts/build-menu-place-index.mjs`.
- Processed wine labels persist in account-scoped IndexedDB. Renewed signed URLs reuse the same cached blob. Exact wine/producer/vintage matches reuse processed artwork. A retained submission receipt can reopen that submission's master artwork, including pending review; this does not publish pending wines or expose unrelated artwork.
- Automatic setup is suppressed for restored/linked sessions, including a late account restore. Manual restart still works.
- One ElevenLabs sound generation (via Runway's eleven_text_to_sound_v2), with two locally edited variations: save, list ready, account link. Local files only, no runtime sound-generation costs, user-interaction unlock, foreground/cooldown guard and Settings mute. Phone audio, not G2 speaker output; no narration.
- Bottle-search network errors, provider throttling, explicit insufficient-credit responses and timeouts receive distinct messages. Search work has a request deadline below the gateway deadline. Failed-to-fetch alone is not a billing diagnosis.
- No schema or permission changes. Existing 10-bottle daily allowance, verified owner exemption, mandatory master contribution outbox and local-only user removal remain in force.
